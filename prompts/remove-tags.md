## Decisions and assumptions

This is a requested feature removal, so I will remove tags from active application behavior.

I will add a forward migration that drops `source_tags` and `tags`, and I will update Drizzle schema metadata through the project workflow if possible.

I will not rewrite old applied migration history such as `drizzle\0000_wild_secret_warriors.sql` unless the project tooling requires generated metadata changes. Historical migrations can still contain old tag SQL because they describe past schema history.

I will remove tag mentions from active docs and prompts that describe current behavior. I will avoid rewriting historical rationale unless needed to stop tests or docs from promising tag behavior.

Retrieval scoping will keep collection filters only.

Source organization will keep collections only.

Knowledge export will keep collections and collection links only.

Remove tag UI from source filters.

Remove tag API inputs from `/api/chat`.

Remove tag creation and attach actions.

Run a final `rg` search and remove remaining active tag references, except immutable historical migration content if needed.

## Security considerations

Keep owner scoping for collections and sources intact.

Keep retrieval filtering owner scoped through collection membership only.

Dropping tag tables removes tag data. This is destructive for any live tag data, and that is expected by this request.

Do not weaken RLS policies on remaining tables.

Do not leave dead API inputs that accept `tagId` silently.

Do not leave export fields that imply tag data still exists.

## Acceptance criteria

No user facing page shows tag controls, tag filters, tag creation, or tag attachment.

`/api/chat` accepts and records collection filters only.

Repository and use case types have no tag DTO, `tagId`, `listTags`, `createTag`, or `addTagToSource` surface.

Drizzle schema has no `tags` or `source_tags` table definitions.

A forward migration removes tag tables and policies.

Tests pass after removing tag expectations.

A final search shows no active source code tag feature references remain.
